# App Store 문안 초안

실제 제휴처와 운영 절차가 확인된 뒤 최종 문안으로 사용합니다. 현재 체험 데이터로 스크린샷을 제출하지 않습니다.

**앱 이름:** 찾아줘

**부제:** 분실물 확인과 회수 상담

**짧은 설명:** 제휴 보관처에 등록된 습득물을 지도에서 찾아보고, 내 물건인지 확인을 요청하세요. 보관처를 알고 있어도 직접 받으러 가기 어렵다면 무료로 회수·배송 가능성을 문의할 수 있습니다.

**주요 기능**

1. 지도와 검색으로 공개된 습득물 확인
2. 공개 설명에 없는 특징으로 소유 확인 요청
3. 보관처를 아는 경우의 회수·배송 가능성 문의
4. 보관처를 모르는 경우의 탐색 상담 접수와 공식 검색 연결
5. 제휴처의 습득물 등록과 운영자 검토 후 공개

**심사 메모 초안:** 찾아줘는 분실물 정보와 문의를 연결합니다. 현재 앱에서 결제나 배송은 이뤄지지 않습니다. 습득물은 권한을 받은 제휴처 직원만 등록할 수 있고, 운영자 검토 후 공개됩니다. 상세 소유 확인 정보는 등록한 제휴처와 요청자, 운영자만 볼 수 있습니다. 계정 삭제는 ‘내 정보 > 계정 삭제’에서 가능합니다. 심사용 이용자·제휴처·운영자 계정은 실제 서버 설정 후 App Store Connect 심사 정보에 제공합니다.

**출시 메타데이터 중 미확정:** 실제 운영사 명칭·고객 지원 연락처, 배포 지역, 개인정보 처리방침 URL, 서비스 이용약관 URL, 제휴처 실데이터, 심사용 계정, iPhone 실기기 스크린샷.
